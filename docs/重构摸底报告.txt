2. fuse_retrieval_candidates（RRF + MMR，indexing.rs:537-670）
RRF 公式（547-553）：reciprocal_rank = weight / (60.0 + rank as f32 + 1.0)，即权重/(60+rank+1)，rank 从 0 起。

通道权重（547-552，按 hit.reason 匹配）：

"filename" | "path" → 1.3
"semantic" → 1.15
"fulltext" → 1.0
其他 → 0.7
每文件 chunk 上限（335 行常量 MAX_FUSED_CHUNKS_PER_FILE = 3；544 行计数器；557-564 行）：(file_id, chunk_id) 为新 chunk 且带 chunk_id 时计数，超过 3 个后该通道的后续 hit 不再累加 RRF 分数（accumulate_rank = false），但仍会进 fused map 补 match_reasons/得分。

得分合并（565-633）：同 key 的 scores.fulltext/semantic/filename 取各通道内 channel_score 最大值（595-631）；fulltext/semantic 命中会补 chunk_id/locator/snippet（612-616、626-630）；match_reasons 去重收集。

MMR 挑选（636-669）：
