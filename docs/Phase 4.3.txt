用户：
“我的资料里是怎么介绍 RAG 的？”

CASE 2：

用户：
“我以前有没有做过 Agent 项目？”

要求：

识别为：

LOCAL_EXISTENCE_QUERY

不要让 LLM 判断。


规则：

有没有做过
是否做过
之前做过
有没有项目

统一：

intent=existence

流程：

Query
↓
Document Resolver
↓
Retrieval
↓
Evidence Check
↓
回答：

有/没有 + 文件依据


禁止生成：

“Agent 是什么”
“自动驾驶 Agent”

避免泛知识污染。
