# 01 首次启动与品牌欢迎

返回：[用户旅程讨论索引](00-讨论索引.md)｜[拾忆 V1 产品与开发规划书](../拾忆-V1-产品与开发规划书.md)

## 1. 用户目标

- 第一次打开拾忆时，快速感受到柔和、克制、与“记忆”相关的品牌气质。
- 在不展示技术细节和功能表单的情况下，理解产品的两句核心主张。
- 主动点击“开始使用”，进入首次使用配置流程。

本节点只承担品牌欢迎，不承担隐私说明、模型检测、目录授权、文件扫描或模型加载。

## 2. 进入条件与完成条件

### 进入条件

- 当前 Windows 用户的本地配置中不存在已完成的当前欢迎页版本；或用户清除了拾忆全部本地数据。
- 软件升级、模型包升级和索引升级不得自动重新触发欢迎页。
- 不同 Windows 用户账户分别维护欢迎状态。

### 完成条件

- 用户已进入第二张画面并主动点击“开始使用”，或在按钮获得焦点后按 Enter/Space。
- `welcome_completed` 成功写入时，本节点永久完成。
- 如果状态保存失败，仍进入节点02，但必须在节点02提示“欢迎状态未能保存，下次可能再次显示”。

### 未完成退出

- 用户在第一张或第二张直接关闭应用时，不写入完成状态。
- 下次启动仍从第一张开始。

## 3. 页面结构与交互步骤

### 3.1 窗口

- 首次窗口在当前显示器中央打开。
- 默认尺寸 `1100×720`，最小尺寸 `900×600`。
- 不自动最大化、不强制全屏，支持用户手动缩放与最大化。
- 保存正常主窗口的位置和尺寸；保存位置已不属于任何有效显示器时，回到主显示器中央。
- 欢迎页采用沉浸式自定义标题栏，渐变背景铺满窗口。

### 3.2 标题栏

- 高度 48px。
- 左上角显示纯文字“拾忆”，不增加图形标识。
- 顶部非交互空白区域可以拖动窗口。
- 双击标题栏切换最大化/还原，从最大化状态拖动时恢复普通窗口。
- 右上角依次显示最小化、最大化/还原、关闭。
- 图标只使用细线，默认浅色；悬停时线条加深。
- 图标视觉尺寸约 16px，实际点击区域不小于 `44×40px`。
- 关闭按钮悬停使用暗玫瑰色线条，不显示突兀的大红色背景。

### 3.3 第一张

- 左上角保持“拾忆”。
- 中央单行显示“拾起你被遗忘的记忆”。
- 第一张不显示“开始使用”按钮、轮播圆点、隐私提示或说明链接。
- 默认停留 3 秒。
- 点击非窗口控制区域，或按 Enter/Space，提前进入第二张。
- 连续点击和重复按键只能触发一次切换。

### 3.4 第二张

- 背景、标题栏和“拾忆”保持不动。
- 中央相同基线单行显示“拾起散落的信息，连接过去的自己”。
- 第二张不再自动循环回第一张。
- 主文案下方约 44px 显示“开始使用”按钮。
- 按钮淡入完成后获得默认键盘焦点。

### 3.5 动画时间线

```text
显示第一句
→ 停留3秒，或用户点击空白处/按Enter/Space
→ 第一句在250ms内淡出
→ 第二句在350ms内原位淡入
→ 延迟150ms后“开始使用”按钮淡入
→ 第二张保持，不循环
```

- 背景、标题栏和窗口控制按钮不参与轮播动画。
- 系统启用“减少动画”时，所有内容切换使用 150ms 简单淡入淡出。
- 动画流程超过 4 秒仍未到达第二张时，看门狗直接显示完整第二张。

### 3.6 “开始使用”按钮

- 只在第二张显示。
- 尺寸 `180×52px`，R角 24px。
- 使用明显的大R角矩形，但不做完全胶囊形。
- 背景为比页面渐变更深的柔和淡粉色，文字为米白色。
- 文字字号 18px、字重 600。
- 悬停时颜色加深；按下时缩放至 98%，约 100ms 后恢复。
- 支持鼠标点击、Enter 和 Space。
- 激活后立即禁用，防止重复进入下一流程。

### 3.7 离开欢迎页

- 欢迎内容与渐变背景在约 250ms 内淡出。
- 在同一个窗口进入节点02“运行环境与模型检测”。
- 米白—淡粉渐变只用于本欢迎页，不延续到后续引导页面。
- 环境检测、模型加载和文件扫描不得阻塞欢迎页退出动画。

## 4. 页面文案

| 位置 | 文案 |
|---|---|
| 左上角 | 拾忆 |
| 第一张主文案 | 拾起你被遗忘的记忆 |
| 第二张主文案 | 拾起散落的信息，连接过去的自己 |
| 第二张按钮 | 开始使用 |
| 最小化无障碍名称 | 最小化 |
| 最大化无障碍名称 | 最大化 |

## 6. 系统输出字段

| 字段名 | 数据类型 | 是否必填 | 默认值 | 校验规则 | 来源 | 展示位置 | 是否持久化 | 敏感级别 | 错误提示 |
|---|---|---:|---|---|---|---|---|---|---|
| `welcome_version` | `string` | 是 | 当前内置版本 | 非空、符合版本格式 | 应用构建 | 不展示 | 是 | 本地一般 | 配置异常时按未完成处理 |
| `welcome_completed` | `boolean` | 是 | `false` | 仅“开始使用”成功激活后可写 `true` | 欢迎流程 | 不展示 | 是 | 本地一般 | 保存失败时在节点02提示 |
| `welcome_completed_at` | `datetime \| null` | 是 | `null` | UTC RFC3339 | 系统时钟 | 不展示 | 是 | 本地一般 | 时间不可用时记录空并保留完成状态 |
| `welcome_stage` | `intro \| transitioning \| action \| exiting \| completed` | 是 | `intro` | 只能按状态机迁移 | 欢迎流程 | 决定当前画面 | 否 | 公开 | 非法迁移回到安全的第二张 |
| `welcome_persist_error` | `AppError \| null` | 否 | `null` | 仅状态保存失败时产生 | 本地配置层 | 节点02通知 | 会话保存 | 本地一般 | 欢迎状态未能保存，下次可能再次显示 |

## 7. API与数据流

### 7.1 本地命令

```text
welcome_get_state() -> WelcomeState

welcome_complete({ welcome_version }) -> WelcomeState
```

`WelcomeState`：

```text
welcome_version: string
welcome_completed: boolean
welcome_completed_at: datetime | null
```

### 7.2 状态机

```text
intro
→ transitioning
→ action
→ exiting
→ completed
```

- `intro` 只接受提前切换和窗口控制。
- `transitioning` 忽略重复切换事件。
- `action` 接受“开始使用”和窗口控制。
- `exiting` 禁用按钮并保存完成状态。
- 保存失败仍进入节点02，并携带 `welcome_persist_error`。

### 7.3 数据边界

- 本节点只读写拾忆自己的欢迎状态配置。
- 不访问用户目录、不读取文件、不建立索引。
- 不启动模型、OCR、解析器或旧 Office 兼容包。
- 不发起任何网络请求，不发送遥测。

## 8. 加载、空状态和错误状态

| 场景 | 行为 |
|---|---|
| 欢迎状态读取中 | 立即显示第一张静态画面，后台读取状态，避免白屏 |
| 状态表明已完成 | 不播放动画，直接进入正常启动流程 |
| 欢迎状态损坏 | 按未完成处理并覆盖为当前 Schema |
| 动画API异常 | 直接显示完整第二张和按钮 |
| 动画超过4秒 | 看门狗直接切换第二张 |
| 重复点击或按键 | 幂等忽略，只执行一次迁移 |
| 欢迎状态保存失败 | 继续节点02，并展示可关闭的本地配置提示 |
| 窗口位置失效 | 在当前主显示器中央恢复默认尺寸 |
| 系统高对比度 | 保留结构，替换为系统可读颜色 |
| 系统减少动画 | 使用150ms简单淡入淡出 |

## 9. 权限与隐私边界

- 欢迎页无需目录权限、网络权限、模型权限和系统管理员权限。
- 不收集账号、联系方式、设备标识或使用统计。
- 不在日志中记录用户点击坐标或可用于行为分析的轨迹。
- 只保存欢迎页版本、完成布尔值和完成时间。
- 自定义窗口按钮必须保留标准的键盘焦点和屏幕阅读器名称。

## 10. 验收场景

1. 新用户启动时第一张立即可见，且不存在“开始使用”按钮。
2. 第一张满3秒后自动切换，点击空白或按 Enter/Space 可以提前切换。
3. 连续点击或长按按键只产生一次切换。
4. 第二句始终单行且与第一句共享中心基线。
5. 第二张显示大R角“开始使用”按钮且不再循环。
6. 鼠标、Enter、Space 均可激活按钮，激活后不能重复触发。
7. 点击按钮后同一窗口进入节点02，欢迎渐变不延续。
8. 首次完成后普通重启和软件升级均不再播放欢迎页。
9. 未点击按钮就关闭时，下次仍从第一张开始。
10. 清除拾忆全部本地数据后再次显示欢迎页。
11. 900×600、1100×720、125%—200%缩放下文案不换行、不裁切。
12. 自定义标题栏支持拖动、双击最大化/还原以及三个窗口按钮。
13. 欢迎阶段不存在网络请求、文件扫描、模型加载和遥测。
14. 欢迎状态保存失败时仍能继续，并在节点02收到明确提示。

## 11. 已确定决策

- 欢迎页只在首次安装后的首次使用中自动出现一次。
- 使用居中普通窗口，不强制全屏或最大化。
- 使用沉浸式自定义标题栏和浅线条窗口控制按钮。
- 背景为静态米白—淡粉渐变，仅用于欢迎页。
- 采用现代无衬线字体，第二句保持单行。
- 第一张无按钮，支持自动、鼠标和键盘进入第二张。
- 两张之间使用原位淡入淡出，不横向滑动、不循环。
- 第二张使用大R角粉色“开始使用”按钮。
- 欢迎页保持纯品牌表达，不展示隐私和技术说明。
- V1 不提供“重播欢迎动画”入口。

## 12. 暂缓事项

- 颜色值、阴影强度和最终字体渲染在视觉原型阶段做像素级微调，但不得改变米白—淡粉、现代无衬线和高对比度边界。
- 应用图标和独立图形 Logo 不属于本节点；欢迎页左上角使用纯文字“拾忆”。
- 节点02负责运行环境与模型检测页面。
- 节点03负责完全本地、源文件只读、索引与缓存说明。
- 本地索引加密策略在安全与存储设计节点中确定。
