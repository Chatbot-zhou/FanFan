# 拾忆 V1 方案逐条审查清单

## 1. 审查规则

状态只使用以下四类：

- `已验证`：存在真实实现，并通过与风险相称的自动测试或运行时验证；
- `部分实现`：存在可运行子链路，但字段、异常、恢复或验收尚未完整；
- `未实现`：只有文档、界面样张、受控示例数据或明确错误返回；
- `暂缓`：规划书明确安排在后续阶段，当前不作为前置阶段完成条件。

页面存在、按钮可点击和浏览器桥接示例数据均不作为后端能力完成证据。每次实现后必须先更新测试，再回写本清单。
