# 拾忆 V1 方案逐条审查清单

## 1. 审查规则

- `已验证`：真实实现已通过自动测试和与风险相称的运行时验证；
- `部分实现`：存在可运行子链路，但契约、异常、恢复、质量或真实环境尚不完整；
- `未实现`：只有旧方案实现、界面、占位数据、文档或受控示例；
- `暂缓`：规划书明确不纳入V1。

旧安装包、浏览器示例数据、按钮存在、历史测试数量和旧规模压力均不证明V1 2.0能力完成。审查状态只能从“代码 → 自动测试 → 真实流程证据”逐级提升。

## 2. 当前代码基线（2026-08-10）

- Rust core：73 passed，4 ignored；桌面Rust：7 passed；`cargo fmt --check`与Clippy `-D warnings`通过；固定Qwen3 GGUF真实本地生成测试另行通过；
- Worker：18 passed，扫描PDF OCR真实运行跳过1项；新构建的独立Worker已通过健康检查、真实Markdown/PDF解析和源文件哈希不变检查；

## 11. 自动验证与发布边界

完成开发后必须运行：

- `cargo fmt --all --check`；
- `cargo clippy --workspace --all-targets --locked -- -D warnings`；
- `cargo test --workspace --locked`；
- Worker单元测试与解析语料；
- TypeScript、Vitest、Vite生产构建；
- 契约和错误码检查；
- 中文搜索/RAG/集合基准；
- 50万文件/500万块合成压力库；
